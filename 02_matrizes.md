# Matrizes

Uma matriz \(m \times n\) é uma tabela de números com \(m\) linhas e \(n\) colunas.

## Operações Principais

- Soma de matrizes (mesma dimensão)
- Multiplicação por escalar
- Multiplicação de matrizes (\(A_{m\times n} \times B_{n\times p}\))
- Transposta (\(A^T\))
- Potência de matriz (\(A^k\))

## Propriedades Importantes

- A multiplicação de matrizes **não** é comutativa em geral
- \((AB)^T = B^T A^T\)
- Matriz identidade \(I\) → \(AI = IA = A\)
